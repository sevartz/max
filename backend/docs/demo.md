# Демо на питче (3 минуты)

Сценарий из [architecture.md §7](architecture.md) на живом боте.

## Подготовка (заранее)

1. Сервер с доменом, `DOMAIN=… docker compose --profile demo up -d --build`, затем seed.
   Для репетиции без MAX: `uv run python -m ctxads.demo`.
2. Тестовый канал «ЗОЖ без фанатизма» с несколькими постами о питании и спорте.
3. Админ пишет боту `/start` → «Принимаю» → добавляет бота админом канала с правами
   «Читать все сообщения», «Публиковать» и «Удалять».
4. В `/settings` включить регулируемую категорию «Медицина» (без этого анализы не предлагаются).
5. Задержка публикации после одобрения — `publish_delay_min` в `channel_settings`
   (по умолчанию 1 минута).

## Показ

1. Публикуем пост «Как бургер влияет на сахар в крови».
2. Через несколько секунд админу приходит «ЛабТест — анализ крови на глюкозу» с объяснением «почему».
3. Жмём «🚫 Не предлагать «Медицина»».
4. Публикуем пост о трагедии → бот молчит, в логах `brand_safety=unsafe`.
   Важно: делайте это, пока нет открытого предложения. Иначе пост отсеется частотным
   правилом «уже есть открытое предложение» ещё до анализа, и brand safety не проявится.
5. Публикуем пост про бег → приходит предложение спорттоваров, медицины больше нет.
6. Одобряем → через `publish_delay_min` в канале рекламный пост с маркировкой
   «Реклама. ООО …, ИНН …. erid: …» и кнопкой «Подробнее».
7. Кликаем → `/stats` показывает клик; начисление CPM появится после опроса просмотров
   (раз в 30 минут), CPC — сразу после клика.

Витрина рекламодателя: `https://<домен>/showcase`.

## Частотные правила (если «ничего не приходит»)

Бот молчит, если: пост короче 80 символов; уже есть открытое предложение; с прошлой
рекламы прошло меньше 3 постов или 120 минут; в сутки уже 3 рекламы; ничего не набрало
порог 0.35. Причина пишется в лог и в `posts.skip_reason`.
