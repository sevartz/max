# Реестр действий мини-приложения

Аудит исходников после исправлений, 29 сентября 2026. «Проверено изолированно» означает тест чистой функции или координатора запросов, а не реальный клик в MAX. Все остальные строки проверены по обработчикам React и серверному контракту. Живые запросы, рекламные размещения и изменения реальных данных не выполнялись.

Обозначения: **изолированно** — Node-регрессия для доменной функции/координатора; **по исходникам** — просмотр обработчика и контракта без запуска интерфейса; **не проверено** — реальное действие в браузере/MAX WebView.

## Автономное демо

Вкладки, каналы, предложения, категорийные переключатели, пауза канала/объявления, список/карточка объявлений, создание, редактирование, пополнение, статистика, примеры состояний и сброс меняют только примерное состояние вкладки. У них нет рабочего API, графиков из выдуманных временных рядов или настоящей оплаты. Денежные поля валидируются; черновик, навигация, раскрытие исходного поста, фокус и прокрутка восстанавливаются после локальной перерисовки. Срок предложения создаётся динамически, истекает по таймеру и отображается с датой и московским временем. «Другой вариант» исчерпывается по сохранённым кандидатам и объясняет недоступность; остальные три решения остаются доступны. Примеры состояний отдельно показывают одобренное ожидание публикации, уже состоявшуюся публикацию и истёкший срок.

## Разбор повторов

- Форма создания кабинета рекламодателя теперь существует только во вкладке «Объявления»; недостижимая страница `brand` удалена из маршрутов.
- В мастере убрана вторая видимая кнопка «Назад». Остаётся один экранный возврат; нативная MAX BackButton вызывает тот же `goBack`, чтобы сценарий работал и в MAX, и в браузерной оболочке. В демо также оставлен один возврат на экран мастера/предпросмотра.
- Ошибка мутации не показывается повторно глобально поверх экранов создания/редактирования/пополнения. Ошибка обновления ресурса остаётся рядом со своим разделом.
- Короткое предложение в строке канала и полная карточка оставлены: первое помогает выбрать канал, вторая раскрывает причину и исходный пост. Сводные показатели рекламодателя и данные по каждому объявлению оставлены, с явными периодами и разными смысловыми группами.
- Кнопка создания в пустом и заполненном списке — два взаимоисключающих состояния с одним действием. «Назад» сохраняет черновик, а «Отменить создание» очищает его после подтверждения; это разные последствия.
- Подпись «Пополнить демо» и короткое предупреждение стоят возле бюджета; форма пополнения повторяет только необходимое пояснение перед вводом суммы. В карточке сохранено отдельное короткое пояснение, что модерация/ERID в этом приложении демонстрационные.
- Основной источник подтверждённых изменений — ответ API. `channelDetails` хранит загруженную карточку, а bootstrap — компактный список; `applyChannel` обновляет обе проекции. `adsData` хранит список/карточку, а `applyAd` синхронизирует тот же ответ в строках статистики. Данные 7/30 дней отдельно принадлежат API статистики.

## Ограничения проверки

- Node изолированные регрессионные проверки и TypeScript-компиляция проверены; production-сборка проверяется отдельно в рамках N2.
- Рабочие действия по реальному API, клики в MAX WebView, реальные ширины, экранная клавиатура, темы, увеличение текста и уменьшение движения здесь не проверялись.
- Визуальная проверка в MAX WebView и на реальных устройствах не выполнена; скриншоты работающего интерфейса не прилагаются.
